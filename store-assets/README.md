# Store Assets

Original artwork only. These folders hold specifications; final graphics and screenshots must be made from the release build.

| Folder | Target | Content |
| --- | --- | --- |
| `icon/` | 512 × 512 PNG, plus adaptive foreground/background | Original red orb on a high-contrast field; avoid text at small size |
| `screenshots/` | At least two phone screenshots, 16:9 to 9:16, 320–3840 px per side | Actual gameplay, combo, shop, and missions screens |
| `feature-graphic/` | 1024 × 500 PNG/JPEG | Original red orb artwork and concise title with safe margins |
| `promotional/` | Sizes as required by each chosen placement | Optional original campaign images |

Check current Play Console specifications before upload. Do not upload these placeholder folders as final assets.
